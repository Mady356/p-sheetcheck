# Contributing

## Week 2 workflow

1. Pull the latest `main` branch.
2. Create a branch for your assignment, for example `week2/andre-extraction`.
3. Work only on the files needed for your task where possible.
4. Commit small, understandable changes.
5. Push your branch and open a pull request into `main`.
6. In the pull request, explain:
   - what you implemented,
   - how you tested it,
   - what is incomplete or uncertain.

Do not wait for everything to be perfect before pushing. The purpose of Week 2 is to create components we can integrate and improve together.
